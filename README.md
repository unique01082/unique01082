I build useful software around real workflows. My current focus is turning [baole.space](https://baole.space) into a connected ecosystem of products and shared foundations for creative work, productivity, and AI-assisted operations.

I tend to build tools for problems I keep running into. Apparently, I run into quite a few.

## Building baole.space

baole.space is growing from a collection of experiments into an ecosystem: focused products with a consistent approach to identity, interfaces, developer tooling, and operations. The aim is simple: make each product useful on its own, while letting the pieces become stronger together.

The work spans creative and photography tools, everyday productivity, AI-assisted workflows, and the infrastructure needed to operate them reliably. Some foundations are open source; other products remain private while their direction and workflows are still being shaped. It is very much a work in progress, but it is a deliberate one.

## Selected public work

- **[LightOps](https://github.com/unique01082/lightops.baole.space)**: A desktop photo file manager for organizing RAW and JPG files from EXIF metadata, built with Tauri, React, and Rust.
- **[lightdrift-libraw](https://github.com/unique01082/lightdrift-libraw)**: A Node.js native addon for decoding camera RAW files, reading metadata, extracting previews, and rendering images.
- **[Rootline](https://github.com/unique01082/folder-structure-sync)**: Safely mirrors directory structures without copying files or deleting existing content.
- **[SVG Motion](https://github.com/unique01082/svg-motion)**: Safe, framework-agnostic SVG animation for TypeScript and React.
- **[@baolq/ui](https://github.com/unique01082/components.baole.space)**: A typed, accessible React component library and dark-first design system.

## Private products & active experiments

*Private / active development*

> Not everything under baole.space is open source. Some products stay private while their foundations, workflows, and product direction are still being shaped.

**Creative and photography**

- **LightNote**: A photography preset journal for organizing editing recipes, color palettes, and visual ideas.
- **LightMark**: A visual annotation and workflow workspace connecting photography review with Lightroom-based data.
- **LightScape**: A PixiJS-powered engine, player, and studio for creating interactive animated 2D scenes.

**AI and product automation**

- **The Many**: A virtual company where AI agents operate as containerized workers with their own workspaces.
- **Pullery**: A GitHub-first issue-to-pull-request control plane.
- **LightFocus**: AI-assisted planning with task prioritization, conversation, and a 3D view of ongoing work.

**Everyday tools**

- **LightKitchen**: An AI-assisted household cooking companion covering inventory, meal planning, shopping, and guided cooking.

## How I build

- Start from real problems and observable user workflows.
- Ship something usable, then refine the architecture with evidence.
- Open-source reusable foundations when they can help other builders.
- Care about reliability, accessibility, and the small details users notice.
